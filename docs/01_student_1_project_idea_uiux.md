## Project Introduction

SkillSwap is a peer-to-peer skill exchange platform for students. It allows students to trade skills instead of paying for tutoring.

Example:

- One student is good at Physics but wants to learn Maths.
- Another student is good at Maths but wants help with Physics.
- SkillSwap helps them discover each other, request a swap, chat, complete a session, and leave a review.

The main idea is simple: students already have useful skills, and SkillSwap gives them a system to exchange those skills fairly.

## Problem Statement

Students often face these problems:

- Students need help learning academic, technical, creative, or language skills.
- Paid tutoring can be expensive.
- Many students already have useful skills they can teach.
- Students may not know who around them can teach or learn a specific skill.
- There is no simple system for students to exchange skills fairly.

## Proposed Solution

SkillSwap allows students to:

- Create a profile.
- Add skills they can teach.
- Add skills they want to learn.
- Discover other students.
- Search by skill, person, university, or category.
- Send swap requests.
- Chat with other students.
- Complete sessions.
- Leave reviews.

Instead of money being the main exchange, the exchange is based on student knowledge.

## Target Users

SkillSwap is designed for:

- University students.
- College students.
- Students who want to learn for free.
- Students who want to help others while also learning something in return.

## Main User Journey

1. User signs up or logs in.
2. User completes their profile.
3. User adds skills they can teach.
4. User adds skills they want to learn.
5. User opens Discover.
6. User finds a matching student.
7. User opens Skill Details or Public Student Profile.
8. User sends a swap request.
9. Other student accepts or declines.
10. Both students chat.
11. They complete the session.
12. They leave reviews.

## UI/UX Design Decisions

The app design is intentionally simple and student-friendly.

- Cards are used to show skills, students, swap requests, reviews, and sessions.
- Bottom navigation is used for the main sections: Home, Discover, Swaps, Messages, and Profile.
- The app avoids looking like a paid course platform such as Udemy.
- The app always focuses on exchange: “I teach X” and “I want Y.”
- The main action on Skill Details is Request Swap, because the app is about starting a skill exchange.
- The screens are clean so a first-time user can understand the flow quickly.

## Ethiopian-Inspired Design Direction

The app uses a warm green and gold color palette.

- Green represents learning, growth, and community.
- Gold gives a local Ethiopian-inspired accent.
- We avoided using red-yellow-green everywhere because that could look too much like a flag theme.
- The result is local, modern, and clean.

This makes the app feel familiar and warm, but still professional for a university demo.

## Possible Teacher Questions

### 1. What problem does SkillSwap solve?

It solves the problem of students needing help but not always being able to pay for tutoring. It lets students exchange skills instead.

### 2. Why is this useful for students?

It helps students learn for free, meet other students, and use skills they already have to gain new knowledge.

### 3. Why did you design the app this way?

We wanted the app to be easy to understand. Students can quickly see what someone teaches, what they want, and how to request a swap.

### 4. Why did you choose this color palette?

Green represents learning and growth. Gold gives a warm Ethiopian-inspired accent. We kept it modern and avoided making it look too much like a flag theme.

### 5. How is this different from normal tutoring apps?

Normal tutoring apps usually focus on paying teachers. SkillSwap focuses on exchanging skills between students.
